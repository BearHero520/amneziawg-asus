# 0.4.0 验证记录

开发环境：Windows amd64；交叉编译目标：Linux ARM64。上游核心固定于 README 所列提交。

## 自动验证

- 37 个顶层 Go 测试通过，包含解析校验、非法脚本拒绝、路径校验、网络命令计划、失败回滚、断线保护及故障切换。
- 官方 Device.IpcSet 接受生成的配置；真实本机 UDP socket 与模拟 TUN 完成 legacy/v2/v3 参数双向加密传输。
- 服务端设备禁用持久化、旧配置默认启用、禁用地址保留、重启配置排除禁用设备。
- 运行中对另一设备添加、禁用、启用、删除后，原设备保持双向传输；检查目标 Peer 的运行核心存在性与原 Peer 握手时间。
- 持久化失败不修改核心；核心更新失败回滚目标设备；回滚失败保留事务标记并阻止继续修改。
- 日志 200 条 / 64 KB 限制、固定非敏感日志字段、只读诊断失败分类。
- 前端测试：请求/响应编码、Unicode、二维码与配置清理、状态轮询与变更竞争、未变化设备行保留、目标 ID、异常事务锁定、全禁用启动阻止、日志和诊断纯文本显示。
- 隔离目录模拟真实安装/服务/卸载脚本，覆盖固件缺少 command 内建命令、有无 cru、缺失依赖、DNS 添加块幂等及保留其他配置。
- 打包验证 ARM64 ELF、文件布局、权限、换行和页面资源存在性。

## 浏览器检查

Chrome 本地模拟后端检查默认服务端、运行时添加设备、日志及诊断显示。原生禁用确认框曾阻塞浏览器自动化；禁用/启用/删除的逻辑由自动测试覆盖，未对真实设备执行这些动作。

## 上游已知测试观察

本开发机原样运行上游 TestAWGDevicePing 曾出现握手后首个 ping/pong 未在测试时限内送达；管理层通信测试采用有限重试通过。没有修改或删除上游测试，也没有修改协议实现。本项目测试通过不等于上游全套测试或性能验收通过。

## 尚待实机验收

0.4.0 尚未部署实机验证。需要在有其他管理通道时验证安装/升级、另一设备持续通信时增删和禁用设备、IPv4/IPv6、NAT66、DNS、WAN 重连、防火墙重载、开机启动、与第三方代理共存及长期性能。

已有版本的外网家庭 LAN 访问和 DNS 查询有实机反馈，不将这些结果视为 0.4.0 全功能验收。诊断仅为路由器本机只读检查，不能证明远端完整链路可用。
