# 0.5.1 验证记录

开发环境：Windows amd64；交叉编译目标：Linux ARM64 与 ARMv7。上游核心固定于 README 所列提交。

## 0.5.1 网页修复验证

- 模拟固件预先加载 RequireJS（define.amd），确认二维码脚本不注册匿名模块，仍保留浏览器全局 qrcode 与 CommonJS 导出。
- 独立二维码解码、Unicode 配置和预览功能回归通过。
- 2026-10-14 在 RT-BE88U 0.4.0 已安装页面热修复二维码资源并刷新后，服务端自动显示已启动、握手和流量，固件侧边菜单恢复；未重启 VPN。控制台未新增匿名 define 错误。
- 本次完整 0.5.1 包仍需实机验收，不将上述前端热修复当作新版核心或 ARMv7 验收。

## 自动验证

- 47 个管理层顶层 Go 测试通过，包含解析校验、非法脚本拒绝、路径校验、网络命令计划、失败回滚、断线保护及故障切换。
- 官方 Device.IpcSet 接受生成的配置；真实本机 UDP socket 与模拟 TUN 完成 legacy/v2/v3 参数双向加密传输。
- 服务端设备禁用持久化、旧配置默认启用、禁用地址保留、重启配置排除禁用设备。
- 运行中对另一设备添加、禁用、启用、删除后，原设备保持双向传输；检查目标 Peer 的运行核心存在性与原 Peer 握手时间。
- 持久化失败不修改核心；核心更新失败回滚目标设备；回滚失败保留事务标记并阻止继续修改。
- 日志 200 条 / 64 KB 限制、固定非敏感日志字段、只读诊断失败分类。
- 前端测试：请求/响应编码、Unicode、二维码与配置清理、状态轮询与变更竞争、未变化设备行保留、目标 ID、异常事务锁定、全禁用启动阻止、日志和诊断纯文本显示。
- 隔离目录模拟真实安装/服务/卸载脚本，覆盖固件缺少 command 内建命令、有无 cru、缺失依赖、DNS 添加块幂等及保留其他配置。
- 打包验证 ARM64 / ARMv7 ELF、文件布局、权限、换行和页面资源存在性。

## 0.5.0 核心更新新增验证

- 清单来源、HTTPS 跳转范围、版本格式、版本比较、ABI / 系列、目标架构、文件大小和 SHA256 拒绝路径。
