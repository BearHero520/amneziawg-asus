# 0.5.2 验证记录

开发环境：Windows amd64；交叉编译目标：Linux ARM64 与 ARMv7。上游核心固定于 README 所列提交。

## 0.5.2 保活和恢复重试验证

- 56 个管理层顶层 Go 测试通过；包括新增的 9 个保活场景测试。完整前端与隔离 Shell 回归通过，ARM64 / ARMv7 交叉编译及安装包结构、ELF 架构校验通过。
- 模拟核心异常且运行状态文件缺失，验证连续失败按 60 / 120 / 240 / 300 / 300 秒重试，到期前不启动；成功后清除重试记录。
- 手动停止在清理失败时仍先保存停止意图；定时检查、WAN/NAT 和同一次开机的启动钩子均不拉起，真实重启重新读取自启选项。
- 健康核心不重启；忙碌锁及恢复过程中到达的新事件均保留，核心更新期间不进行恢复。
- 固件临时停止与用户停止分开处理；固件服务恢复保留运行意图，不能覆盖用户手动停止。
- 清理失败不启动新核心；未完成设备事务阻止自动重建；失败日志隐藏私钥并保留阶段与成功记录。
- 页面在等待恢复时允许停止并取消重试，停止后按钮状态恢复；其余设备热修改与请求竞争回归通过。
- 自动测试故障均为隔离注入，不表示已验证真实 WAN 断线、断电或长期运行。
